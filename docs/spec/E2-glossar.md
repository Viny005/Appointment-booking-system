# E2 — Glossar

| Begriff | Bedeutung |
|---|---|
| Berater / Advisor | Internes Profil, mit dem Kunden Termine buchen können. |
| Primärberater | Profil, das der Kunde auf der Startseite ausgewählt hat. |
| Zusätzlicher Teilnehmer | Weiterer Berater, der aufgrund einer Profilbeziehung angeboten und ggf. ausgewählt wird. |
| Gast | Externe Person, die nur über eine zusätzliche E-Mail-Adresse zu einem Termin eingeladen wird. |
| Service | Buchbarer Termingrund eines konkreten Profils mit Dauer und Meetingmodus. |
| Wochenverfügbarkeit | Wiederkehrende Verfügbarkeitsintervalle je Wochentag. |
| Ausnahme | Konkrete Abweichung vom Wochenmuster an einem Datum. |
| Slot | Möglicher Startzeitpunkt eines Termins. |
| Buchungshorizont | Wie weit im Voraus ein Kunde buchen darf; initial 3 Monate. |
| Mindestvorlauf | Zeit zwischen Buchungszeitpunkt und Terminbeginn; initial 24 Stunden. |
| `.ics` | iCalendar-Datei für Kalenderprogramme. |
| Verwaltungslink | Sicherer Link, mit dem ein Kunde ohne Konto seinen Termin verwaltet. |
| Anonymisierung | Entfernung personenbezogener Daten unter Erhalt fachlicher Historienmetadaten. |
| Profilbeziehung | Konfiguration zwischen zwei Beraterprofilen, z. B. Merveil → Fabrice. |

| Ergänzender Begriff | Bedeutung |
|---|---|
| MeetingModePolicy | FIXED oder CLIENT_CHOICE als Service-Auswahlregel |
| MeetingMode | Tatsächliche Terminform IN_PERSON, PHONE oder ONLINE |
| Profilstatus | DRAFT, ACTIVE oder INACTIVE, unabhängig vom Benutzerkonto |
| Resend | Bewusst neuer Bestätigungsversand, keine neue Buchung oder Kalendersequenz |
